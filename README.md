# Currículo API

API REST do meu app currículo, feita com Express + TypeScript + PostgreSQL (NeonDB) e publicada no Vercel. Ela alimenta o app em React Native + Expo. Tem como funcionalidade extra **Download do currículo em PDF**.

## Tecnologias
 - Express + TypeScript, hospedado no Vercel
 - PostgreSQL no NeonDB, acessado com o driver pg
 - zod para validar os dados do CRUD
 - pdf-lib para gerar o PDF do currículo
 - Postman para testar todas as rotas
